# prediccion_suscripcion
Predicción de suscripción a depósito bancario — Proyecto grupal (Python, TensorFlow)
Trabajo en equipo (3 integrantes) sobre el dataset Bank Marketing (UCI), con más de 45.000 registros. Desarrollé un modelo baseline de Regresión Logística y detecté fuerte desbalance de clases que limitaba el recall (34%). Diseñé e implementé una Red Neuronal (Keras/TensorFlow) con regularización L2, Dropout, Early Stopping y ponderación de clases, mejorando el recall de la clase minoritaria de 34% a 89%, priorizando la detección de clientes potenciales sobre la exactitud global.
